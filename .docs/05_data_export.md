# Exportación de Datos (Excel / CSV)

## Objetivo
Facilitar el traspaso de información contable y de stock a herramientas de oficina para administración avanzada.

## Requerimientos Técnicos
1. **Librerías**: Utilizar `excel` o `csv` para la generación de archivos.
2. **Flujo de Usuario**:
   - En `SettingsPage`, agregar un ícono para "Exportar Datos".
   - Permitir al usuario elegir un rango de fechas (ej. último mes).
3. **Integración con Sistema Operativo**:
   - Usar `share_plus` para que el usuario pueda enviarse el archivo por WhatsApp, Email, o guardarlo en archivos.

## Beneficios
- Facilidad para los contadores.
- Independencia de los datos del usuario.
